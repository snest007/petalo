# H4 AnalyticalTable acceptance

H4 ports WCR's `useToggleRowExpand` and Expandable renderer for `isTreeTable`, row data access, controlled/default expansion, keyboard disclosure and `onRowExpandChange`. It ports `useRowSelect`, `useRowSelectionColumn`, `useSingleRowStateSelection` and `useSelectionChangeCallback` for the three selection modes and behaviors, select-all, range selection, controlled/default IDs, `onRowSelect`, `onRowClick`, and localized announcements. The plugin equivalents are `indeterminateRowSelection`, opt-in `selectSubRows`, `manualRowSelect`, `isRowSelectable` and `shouldIgnoreRowClick`. The disabled-selection plugin disables select-all.

`renderRowSubComponent` supports four explicit WCR modes and `alwaysShowSubComponent` with measured heights and keyboard focus navigation. Omitting the mode preserves the existing all-row details slot. The Custom demo exercises that slot. Row indicators cover `withRowHighlight`, `highlightField`, `withNavigationHighlight`, `markNavigatedRow` and `onRowContextMenu`.

## Paired evidence

The WCR pixel matrix passed 9/9. All 171 new fixture cells matched in dimensions. The largest difference was 1.5414% for `analytical-table-details-included-expandable` in High Contrast White compact. There were no skipped cells or tolerance changes. Both WCR accessibility trees passed. No stored tree-baseline entry was added.

The WCR-specific declarations in the paired fixtures check exact disclosure, hierarchy, name, reference and wrapper paths. WCR's `useStyling.getRowProps` omits row-level hierarchy. WCR's `Expandable.js` names its Horizon buttons on focus and sets button-level expanded only when true. Petalo exposes the tree hierarchy, persistent disclosure names and both expanded states. A paired behavioral test checks the row and cell states and the native focus-dependent label. The comparator unwraps only validated inert, form-associated shadow hosts.

The detail wrapper in WCR's `RowSubComponent.js` is focusable and lacks the required `gridcell` role. The comparator verifies both wrapper shapes, the same focusable inspector and the complete detail contents. WCR's `useRowDisableSelection` exposes an unnamed checkbox and leaves a Select All instruction after removing the action. Petalo names the disabled checkbox, keeps its checked and disabled states, and removes that instruction. The synthetic-header comparator verifies the original WCR label and the identical text Petalo adds for axe's `empty-table-header` rule.

Petalo's fixture and docs axe checks passed. The pinned WCR fixture audit records the expected native-only findings in each theme and direction. It checks the rule, count and offending markup for the ten detail wrappers, one unnamed disabled checkbox and, in regular Horizon, fifteen unfocused disclosure buttons.
