# H12 — ActionSheet acceptance

The item is available as `@petalo/action-sheet`. It composes ResponsivePopover with
an owned trigger and ordered native buttons. Desktop uses an anchored popup. The
phone uses a bottom-aligned dialog with the supplied title and an optional Cancel.
The component supports controlled visibility, experimental part styling and text
overrides. P4 owns the parity inventory, and H12 owns the WCR localization inventory.
