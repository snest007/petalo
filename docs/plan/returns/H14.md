# H14 — AI action for table column headers

`@petalo/table` exports `TableHeaderCellActionAI` for the existing
`TableHeaderCell.action` slot. The action uses the SAP AI icon and transparent
button. When the column moves into a responsive pop-in, the row shows the
action beside its label with the smaller native icon. The callback receives the
button that was activated. `Table.texts.generatedByAI` supplies the tooltip,
accessible name and the focused cell's AI description. The demo and two
Storybook stories show how to reveal the origin of a suggested value.
