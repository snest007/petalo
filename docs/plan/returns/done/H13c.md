# H13c — Notification settings views

`@petalo/user-settings-dialog` now exports `UserSettingsNotificationsView` and
adds the Switch registry dependency. The view composes named primary and
secondary lists, group headers and header form rows. Consumers can control
checked state, veto navigation, supply custom end content and style owned
parts. The dialog opens the matching sibling by item key, uses the native
fallback title, and restores the originating row's focus on Back. Visited
pages retain their switch state while hidden and inert. The demo and
Storybook show the primary and secondary forms.
